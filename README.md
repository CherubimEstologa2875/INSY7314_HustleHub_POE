# HustleHub+ Express Starter

This folder contains a minimal Node.js and Express.js setup for HustleHub+.

## What is included

- `src/server.js` starts the server.
- `src/app.js` configures Express.
- `GET /api/health` returns a simple JSON response.

## Setup

```bash
npm install
npm run dev
```

Then open:

```text
http://127.0.0.1:3000/api/health
```
